几个常问的

不 root 能装吗
能。KSU 商店本身不需要 root，浏览、搜索、下载、收藏都能用，只是装模块那一步要用到 root 权限。投屏也只有「免弹窗采集」这一项要 root，其余走系统授权，不 root 一样投。
为什么不收费
因为没有要花钱的地方。没有服务器要租，没有账号系统要维护，下载流量交给 GitHub 的静态托管。既然成本接近零，就没有理由收钱，也懒得做广告。
我的数据在哪
全在本机。已装模块、收藏、下载记录、头像和昵称都存在应用自己的目录里，不上传。所以换手机不会同步，卸载重装也会清空。覆盖安装（同一个签名）会保留。
装不上或者被系统拦了怎么办
先在系统设置里允许这一个来源安装未知应用。如果提示「签名不一致」，说明手机上还留着别的版本，先卸载再装——这样会清掉本机数据。两个应用都要装，就去各自的官网下最新的包。
