它是一把一次性的钥匙，不是一扇门。

常见的 root 方案会把自己装进系统里：开机自启、发授权、管模块。Dopamine 反过来，它只在按下那一刻有效。进程结束、手机重启，权限跟着消失。

临时 root，重启即失效

权限只活在本次开机里。不需要手动清理，也不会有东西在你不知情的时候继续跑。用完想收回，重启一次就干净了。

不刷机，不碰分区

不用解锁 bootloader、不写 boot 分区、不动系统镜像。原来的系统原封不动，你的数据和设置也不会被清掉。

参数可以自己调

不同机型的内核偏移不一样，偏移不一样结果就不一样。支持导入 HOCon 格式的 offsets.conf（v2），也能直接改参数覆盖。

每一步都留记录

攻击日志、内核 dmesg、pstore 都能导出成文件。失败时能看清是哪一层对不上，而不是只得到一个「失败」。

为什么不做成常驻 root。

常驻意味着有东西一直留在系统里，开机就起、一直有权限、要管模块要发授权。这套东西一旦装上去，就很难再说清楚「它现在在做什么」。

常驻方案要付出的

  • 解锁 bootloader，部分机型会清空数据并失去保修。
  • 写 boot 分区，刷错一次就是开机黑屏。
  • 开机自启的守护进程，权限一直在，要自己盯。
  • 装了模块、改过系统，之后想退回去得再刷一遍。

Dopamine

  • 只在本次开机有效，重启自动失效，不留门。
  • 不写系统分区，不动 boot，出问题重启就好。
  • 没有常驻进程，也不用给它发长期授权。
  • 想用就用，不想用就当没装过。

常问的几件事

重启之后 root 还在吗？

不在。这是临时 root，重启即失效，这是它本来的设计，不是没做完。想让 root 每次开机都在，得用 KernelSU 或 Magisk 那类常驻方案。

和 KernelSU、Magisk 有什么区别？

那两个是常驻的 root 管理器：装模块、发授权、重启还在。Dopamine 只做提权这一件事，做完就结束，不接管之后的权限管理。目的不同，不能互相替代。

会不会把手机搞坏？

正常不会，因为整个过程不写系统分区。中途重启，开机还是原来的系统。反复失败可以打开「安全模式」，把已加载的模块全部禁掉再试。

提示内核不支持怎么办？

先确认内核版本在 Linux 5.10.236 ~ 6.6.127 之间。在区间内还失败，多半是 offsets 对不上：去设置里导入对应机型的 offsets.conf（v2），或打开参数配置手改，再把 debug 日志导出来看停在哪一步。

日志在哪，反馈问题要发什么？

设置里打开「导出 Debug 日志到文件」后，写在 Download/dopamine-debug-log 目录里，包含攻击日志、dmesg 和 pstore。要反馈问题，把这几份一起发过来最有用。

为什么只发 arm64？

这套逻辑依赖 64 位内核的地址布局。32 位设备的内核结构差别很大，不是改个参数能对上的，所以干脆不发，免得装了也跑不通。

隐私政策

更新日期 2026 年 11 月 7 日 · 生效日期 2026 年 11 月 7 日

Dopamine（以下简称「本应用」）是一个在设备本地运行的权限获取工具。本政策说明本应用处理哪些信息、为什么处理，以及你可以如何控制。

我们不做什么

  • 不需要注册账号，不收集手机号、身份证、通讯录、短信、位置轨迹。
  • 不上传你的设备信息、已装应用列表或执行结果。
  • 不接入广告 SDK，不做用户画像，不向第三方出售或共享个人信息。

我们处理哪些信息

  • 执行日志：每一步的进度与结果，保存在本机日志目录，仅在你主动开启「导出 Debug 日志」后写入文件。
  • 参数与配置：你导入的 offsets.conf 内容与手改的参数，保存在本机应用私有目录。
  • 已装应用列表：用于「通过 Shizuku 执行」时判断 Shizuku 是否可用，仅在本机判断，不上传。
  • 版本检查：启动时向公开地址读取版本清单，只用于比对是否需要更新。

权限与用途

  • 网络与网络状态：下载完整包、读取参数更新、检查版本。
  • 查询已装应用：判断 Shizuku 等依赖项是否存在。
  • 悬浮窗：执行过程中在系统上层显示进度，可随时关闭。

存储与共享

全部配置、日志与记录保存在本机应用私有目录或你指定的下载目录，卸载即删除。除完成你发起的请求所必需外，我们不会向任何第三方提供你的信息。

你的权利

  • 随时在系统设置中撤销网络、悬浮窗、查询已装应用等授权。
  • 在应用内关闭日志导出，或直接删除日志目录。
  • 卸载应用可删除全部本地数据。

未成年人保护

本应用涉及系统级权限操作，不面向未成年人单独提供服务。若你是未成年人，请在监护人陪同下阅读本政策并使用。
